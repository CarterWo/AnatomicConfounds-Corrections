# Spatial Transcriptomics Analysis Pipeline

This repository contains the full analysis pipeline for spatial transcriptomics data generated on the CosMx SMI platform. The pipeline moves from raw CosMx exports through preprocessing, differential expression (DE), and post-DE comparison.

---

## Repository Structure

```
├── EzySeq_Library/          # Custom Python library (ezy_seq)
├── Pre_processing/          # Data loading, annotation, and region labeling
├── DE_scripts/              # Differential expression (R, Jupyter kernel)
├── Post_DE_Processing/      # DE result comparison and meta-analysis
├── Visualization_Scripts/   # UMAP and volcano plot generation
├── Quint_Scripts/           # Quint atlas region assignment (R)
└── Final_Data/              # Processed outputs
```

## Pipeline Overview

### Step 1 — Preprocessing (`Pre_processing/Pre_DE_processing.ipynb`)

This notebook takes raw CosMx exports and produces annotated, normalized AnnData objects ready for DE.

**1a. Load raw data**
```python
import ezy_seq as ezy
adatas = ezy.load.cosmx("/path/to/cosmx/export")
meta_dictionary = ezy.read_dictionary("sample_info.xlsx")
```
`ezy.load.cosmx` reads all CosMx slide exports in a directory. `ezy.read_dictionary` reads a sample metadata Excel file mapping sample IDs to experimental groups (e.g., FMT treatment).

**1b. Assign sample IDs via Napari polygons**

Hand-drawn polygon CSVs exported from Napari are used to assign cells to samples. Each CSV is named by sample ID and contains `axis-0`/`axis-1` vertex columns.

**1c. Annotate and normalize**
```python
annotated = ezy.apply_annotation(adatas, meta_dictionary, cell_type_key="<seurat_cluster_col>")
normalized = ezy.filter_and_normalize(annotated, min_gene_cnt=15, min_t_cnt=20)
adata_full = sc.concat(normalized, join='outer', merge='first', index_unique='-')
```
`apply_annotation` maps cluster labels and sample metadata onto each AnnData. `filter_and_normalize` applies per-cell gene/transcript count thresholds and log-normalizes.

**1d. Export to R/Seurat**
```python
export_anndata_for_seurat(adata_full, output_dir="./seurat_export")
```
Writes `normalized_counts.csv`, `raw_counts.csv`, `cell_metadata.csv`, `features_counts.csv`, `coords_xy.csv`, `pca.csv`, and `umap.csv` for Seurat import.


**1e. Assign anatomical regions**

Two region annotation strategies are used:

- **Napari** (`napari_region`): polygon CSVs drawn per brain region (Cortex, Hippocampus, Cerebellum, etc.) are used to label each cell via point-in-polygon testing.
- **Quint** (`quint_region`): atlas-based region assignments generated by the Quint pipeline (`Quint_Scripts/Quint_Pipeline.Rmd`) and joined by cell index.

**1f. Create cell type labels**
```python
# Simplified cell types (e.g., "Astrocytes.cortex.hippocampus" -> "Astrocytes")
adata_full.obs['ct_simple'] = ...

# Combined labels (cell type + region)
adata_full.obs['ct_napari_region'] = adata_full.obs['ct_simple'] + "_" + adata_full.obs['napari_region']
adata_full.obs['ct_quint_region']  = adata_full.obs['ct_simple'] + "_" + adata_full.obs['quint_region']
```

**1g. Create region-enriched subsets** (stroke manuscript specific)

`set_region_abundance_by_FMT` proportionally samples cells so that Cortex representation differs between experimental groups, producing `cortex_up` and `cortex_down` AnnData subsets used in sensitivity analyses.

**1h. Export for pseudobulk DE**
```python
ezy.pseudobulk_export(adata_full, group_by=["sample_ID", "ct_simple"])
```

### Step 2 — Differential Expression (`DE_scripts/LMM_all.ipynb`)

This notebook runs in an **R kernel**. It takes the CSV exports from Step 1 and runs three DE models.

| Model | Method | Output file pattern |
|-------|--------|-------------------|
| DREAM | `variancePartition::dream` | `{UP\|DOWN}_{celltype}_dream_{annotation}.csv` |
| Seurat | `FindMarkers` (LR test) | `{UP\|DOWN}_{celltype}_seurat_{annotation}.csv` |
| DESeq2 | Pseudobulk | `DESEQ2{UP\|DOWN}_{celltype}_PB.csv` |

**Annotations** refer to the region labeling strategy: `napari`, `quint`, or `blind` (no region stratification).

Each output CSV contains one row per gene with logFC and significance columns. `UP`/`DOWN` indicates the direction of the effect in the primary comparison group.

---

### Step 3 — Post-DE Processing (`Post_DE_Processing/LMM_output_procesing.ipynb`)

This notebook loads and compares DE results across models and annotation strategies using `ezy_seq.lmm`.


**File naming convention** expected by `ezy_seq.lmm`:
```
{UP|DOWN}_{celltype}_{model}_{annotation}.csv   # DREAM / Seurat
DESEQ2{UP|DOWN}_{celltype}_PB.csv               # DESeq2 pseudobulk
```

### Step 4 — Visualization (`Visualization_Scripts/UMAPS.ipynb`)

```python
import ezy_seq as ezy

# UMAP colored by any obs column
ezy.plot.umap(adata_full, color_by="ct_simple", groups=[("FMT", ["Healthy", "MCI"])])

# Volcano plot from rank_DE output
de_results = ezy.rank_DE(adata_full, groupby="FMT", comparisons=[["Healthy", "MCI"]])
ezy.plot.volcano(de_results, y_axis="score", top_labels=30)
```

## ezy_seq Library Reference

| Function | Description |
|----------|-------------|
| `ezy.load.cosmx(path)` | Load all CosMx slide exports from a directory |
| `ezy.read_dictionary(xlsx)` | Read sample metadata from Excel |
| `ezy.apply_annotation(adatas, meta, cell_type_key)` | Map cluster + sample metadata onto AnnData list |
| `ezy.filter_and_normalize(adatas, min_gene_cnt, min_t_cnt)` | Filter by gene/transcript counts, log-normalize |
| `ezy.combine_adatas(out_path, adatas)` | Concatenate and save AnnData list |
| `ezy.rank_DE(adata, groupby, comparisons)` | Wilcoxon DE across one or more group pairs |
| `ezy.stouffer_signed(results, weights)` | Stouffer meta-analysis combining signed statistics |
| `ezy.wilcoxon_stouffer_by_region(adata, ...)` | Region-stratified Wilcoxon + Stouffer combination |
| `ezy.pseudobulk_export(adata, group_by)` | Aggregate to pseudobulk counts for bulk DE methods |
| `ezy.plot.volcano(de_df, ...)` | Volcano plot with optional gene labeling |
| `ezy.plot.umap(adata, ...)` | UMAP plots with group filtering |
| `ezy.plot.rank_and_plot(adata, ...)` | Rank genes and plot top features |
| `ezy.plot.feats_bar(de_df, ...)` | Horizontal bar chart of top DE features |
| `ezy.lmm.*` | DE result loading, correlation, overlap, and concordance utilities |
